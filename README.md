# High-Mate

**AI 기반 하이라이트 편집 어시스턴스**

High-Mate는 실시간 스트리밍 영상에서 채팅 속도, 채팅 감정, 음성 감정 분석을 활용하여 하이라이트 구간을 추천하고, 편집자가 맥락을 이해한 후 효율적으로 클립을 선택할 수 있도록 돕는 AI 기반 편집 어시스턴스 시스템입니다.

## 📌 프로젝트 개요

### 배경
실시간 스트리밍 플랫폼의 이용이 급증하면서 인터넷 방송 콘텐츠가 양방향 소통 중심으로 변화하고 있습니다. 하지만 긴 영상에서 하이라이트를 찾아 편집하는 작업에 많은 시간과 노동력이 소모되며, 기존 자동 편집 도구들은 시청자의 반응이나 스트리머의 감정을 정확히 반영하지 못한다는 한계가 있습니다.

### 핵심 기능
- 📊 **채팅 속도 분석**: 실시간 채팅 반응이 급증한 구간 감지
- 😊 **채팅 감정 분석**: 시청자 감정(기쁨, 슬픔, 놀람, 중립) 분류
- 🎤 **음성 감정 분석**: 스트리머의 감정(기쁨, 슬픔, 분노, 중립) 추출
- 🎯 **하이라이트 추천**: 다차원 분석 기반 편집 구간 자동 추천
- 📈 **직관적 시각화**: 리스트/그래프 형태의 결과 제공

## ✨ 주요 특징

### 차별점
기존 서비스들과 달리 단순한 수치 기반이 아닌 **채팅창 반응 속도 + 감정 변화 분석**을 함께 활용하여, 시청자와 스트리머의 심리적 반응과 실시간 분위기를 동시에 파악할 수 있습니다.

![화면 녹화 중 2025-06-13 022824](https://github.com/user-attachments/assets/4b650685-215b-46ae-9037-ea773bd3a302)

- ⚡ **빠른 처리 속도**: 40분 영상 기준 10분 이내 처리 (기존 15~20분 대비 50% 단축)
- 🎭 **맥락 이해**: 단순 반응량이 아닌 감정 정보 제공으로 상황 파악 용이
- 🔍 **다양한 필터링**: 감정별, 크기별 정렬로 원하는 구간 빠른 탐색
- 📹 **미리보기 기능**: 각 구간의 썸네일과 영상 미리보기 제공

## 🛠 기술 스택

### AI/ML
- **텍스트 인식**: YOLOv5 + DTRB (Deep Text Recognition Benchmark)
- **텍스트 감정 분석**: KoBERT 기반 Bi-LSTM
- **음성 감정 분석**: Wav2Vec2 + openSMILE + Fusion MLP

### Frontend
- **PyQt5**: 데스크톱 애플리케이션 GUI

### 주요 라이브러리
- PyTorch
- Pytesseract
- Transformers (KoBERT, Wav2Vec2)
- openSMILE

## 📊 모델 성능

| 모델 | 정확도 | 비고 |
|------|--------|------|
| 텍스트 인식 (OCR) | 약 80% | 어두운 배경, 높은 대비에서 최적 성능 |
| 채팅 감정 분류 | 약 68% 이상 | 복합 감정 문장에서 다소 낮은 정확도 |
| 음성 감정 분류 | 약 77% | 11 에폭 이후 안정적 수렴 |

## 📱 화면 구성

### 메인 화면
영상 업로드 및 채팅창 드래그 기능 제공

### 결과 화면 - 리스트
- 구간별 썸네일, 시작/종료 시간
- 시청자/스트리머 감정 정보
- 채팅 속도 (초당 채팅 수)
- 감정별 정렬/필터링

### 결과 화면 - 그래프
- 시간축 기반 감정 분포 그래프
- 채팅 속도에 따른 높이 변화
- 감정별 색상 구분
- 클릭/호버로 구간 정보 확인

## 🎯 활용 분야

### 1. 개인 스트리머 및 편집자
유튜브, 치지직 등에서 활동하는 스트리머의 하이라이트 클립 제작

### 2. 스트리밍 분석 플랫폼
실시간 방송 데이터 분석 플랫폼에서 콘텐츠 반응 평가 지표로 활용

### 3. 확장 가능성
- 실시간 방송 중 하이라이트 자동 추출 기능
- API 형태로 영상 편집 툴과 연계
